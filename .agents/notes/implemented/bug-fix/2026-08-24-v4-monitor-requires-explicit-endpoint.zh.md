# Agent Note: V4 监控要求显式端点

Status: implemented

[English](2026-08-24-v4-monitor-requires-explicit-endpoint.md) | 中文

## Problem

V4 监控插件曾把一个特定部署的公网 IP 作为仓库默认值。虽然空邀请码阻止了鉴权请求，但新安装仍会继承一个自己没有选择的部署信息。

## Decision

`local-v4` 的监控地址与邀请码现在都默认为空。只有两个值同时存在时，服务才会发起网络请求；用户通过插件设置界面配置它们。既有本地设置继续覆盖空默认值。

## Alternatives considered

**保留端点，只依赖空邀请码。** 这种方式可以阻止鉴权轮询，但仍会让某个部署地址进入每一份安装配置，而且一次凭据编辑就可能意外开始向该地址发送流量。

## Consequences

全新安装不再暴露任何监控目标或凭据。仅打开侧栏状态条不会产生流量；用户必须提供两个连接参数。已经保存这两个值的既有安装无需迁移，并会继续轮询。
